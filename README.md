### 👋 Hey, I'm Thomas

I'm a **software engineer from Cairo** who likes turning messy business problems into products people actually enjoy using.
I started out building native Android apps, and today I work across the **whole stack**: mobile, web, backend, desktop, and lately **AI**.

- 📱 Building **OneApp** at **_VOIS (Vodafone Group)**, a multi-country React Native app used by millions
- 🏗️ Designing **ERP, POS and back-office platforms** from database schema to pixel
- 🤖 Building **AI features**: an Arabic-first *Chat-BI* assistant that answers business questions in plain language (NL → validated SQL)
- 🧩 Maintaining open-source tooling like [`generic-logger`](https://github.com/thomassamoul/generic-logger) and a [Clean Architecture Android Studio plugin](https://github.com/thomassamoul/CleanArchitectureBoilerplatePlugin)
- ⚡ Fun fact: I have a degree in **Accounting**, so I read balance sheets as well as stack traces
